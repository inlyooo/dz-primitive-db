# Примитивная база данных

Домашнее задание №2 по программированию на Python.
Автор: Кислицын Дмитрий Геннадьевич.

Консольная база данных умеет создавать таблицы, добавлять, выбирать, изменять
и удалять записи. Схемы сохраняются в `db_meta.json`, записи — в `data/<таблица>.json`
в текущем рабочем каталоге. После перезапуска данные остаются на месте.

## Установка и запуск

Нужны Python 3.12+ и [uv](https://docs.astral.sh/uv/getting-started/installation/).

```bash
git clone https://github.com/inlyooo/dz-primitive-db.git
cd dz-primitive-db
uv sync --frozen
uv run database
```

Если установлен Make, доступны те же действия: `make install` и `make run`.
В Windows можно использовать команды `uv` напрямую.

## Управление таблицами

```text
create_table users name:str age:int is_active:bool
list_tables
info users
drop_table users
```

Поддерживаются `int`, `str`, `bool`. Столбец `ID:int` добавляется автоматически
в начало схемы. Его также можно указать явно один раз. Имена таблиц и столбцов
должны быть идентификаторами: например, `users`, `is_active`.

## CRUD-операции

```text
insert into users values ("Sergei", 28, true)
select from users
select from users where age = 28
update users set age = 29 where name = "Sergei"
delete from users where ID = 1
```

Все поля обязательны. При добавлении записи значения передаются в порядке
столбцов, без ID. Новый ID равен максимальному ID существующих записей плюс один;
для пустой таблицы — 1. Изменять ID командой `update` нельзя.

Строки заключаются в одинарные или двойные кавычки; в них допустимы пробелы
и запятые. Числа записываются без кавычек, логические значения — `true` или `false`.
Условие `where` поддерживает одно равенство. Для `update` и `delete` оно обязательно.
В `set` можно указать несколько присваиваний через запятую.

Перед удалением записей или таблицы программа запрашивает подтверждение `y/n`.
Любой ответ, кроме `y`, отменяет операцию. Ошибки ввода выводятся в консоль,
после чего можно ввести следующую команду. `insert` и `select` показывают время
выполнения. Повторные выборки кешируются; изменение данных сбрасывает кеш.

`help` показывает справку, `exit` завершает работу.

## Проверка и сборка

```bash
uv run ruff check .
uv run python tests/run_tests.py
uv build
```

Либо: `make lint`, `make test`, `make build`.
Проверки используют временные каталоги и не меняют рабочую базу.
Библиотеки приложения: `json`, `shlex`, `time`, `os`, `prompt`, `prettytable`.
Тесты дополнительно используют стандартную библиотеку Python.
